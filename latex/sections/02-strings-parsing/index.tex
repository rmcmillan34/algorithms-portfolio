\section{Strings \& Parsing}

Strings are a fundamental data structure used to represent text and sequences of characters.
They often require specialized algorithms for efficient manipulation, searching, and pattern matching.
This chapter focuses on recognizing string-based problem patterns and maintaining clear invariants over character sequences.

\subsection{Core Ideas}
\begin{itemize}[nosep]
  \item Two-pointer techniques for substring problems
  \item Sliding window approaches for dynamic substring analysis
  \item Character classification and normalisation
  \item Maintaining loop invariants over indicies
  \item Incremental Parsing
  \item In-place vs Auxiliary Storage
\end{itemize}

\subsection{Common Pitfalls}
\begin{itemize}[nosep]
  \item Off-by-one errors at boundaries
  \item Incorrect handling of empty strings or single-character strings
  \item Failing to advance pointers correctly when skipping characters
  \item Unnecessary string copying leading to increased time/space complexity
  \item Assumptions about character sets (e.g., ASCII vs Unicode)

\end{itemize}
