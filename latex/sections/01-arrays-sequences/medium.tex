\subsection{Medium}

In the medium array and sequence problems, the core challenge shifts from straightforward iteration to designing a lightweight strategy that stays correct as the data evolves. 
You’ll see patterns like two pointers, sliding windows, prefix sums, and careful in-place updates—techniques that let you trade brute force for structure. 
The goal is to identify the right state to carry forward (counts, window bounds, best-so-far answers, or monotonic properties) and update it efficiently, often in linear time. 
More than anything, these problems reward disciplined thinking: define the invariant, update it in constant time, and make each pass through the array “pay for itself.”
