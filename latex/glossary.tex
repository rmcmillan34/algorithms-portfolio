\section*{Glossary}
\addcontentsline{toc}{section}{Glossary}

\begin{description}[leftmargin=2.5cm,style=nextline]

  \item[Amortized analysis]
  An analysis technique that considers the average cost of operations over a
  sequence of operations, even if individual operations may be expensive.

  \item[Invariant]
  A property that remains true before and after each iteration of an algorithm
  or loop.

  \item[In-place algorithm]
  An algorithm that transforms its input using only a constant amount of
  additional memory.

  \item[Loop invariant]
  An invariant associated with a loop, used to prove correctness via
  initialization, maintenance, and termination.

  \item[Time complexity]
  An asymptotic measure of how an algorithm’s running time grows as a function
  of input size.

\end{description}
